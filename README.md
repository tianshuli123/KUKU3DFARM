# 李天舒 · 3D 设计师作品集

纯静态站点：`index.html` + `styles.css`，**没有构建步骤、没有依赖、不请求任何外部字体或 CDN**，所以国内打开快，也不会因为某个 CDN 被墙而白屏。

---

## 1. 先看效果

双击 `index.html` 就能在浏览器里打开。

想在手机上预览：在 `portfolio` 目录里开一个本地服务，然后用手机连同一个 Wi-Fi 访问电脑 IP。

```powershell
python -m http.server 8080
```

## 2. 要改的地方（约 10 分钟）

打开 `index.html`，从上往下改：

| 位置 | 改什么 |
|---|---|
| `<title>` 和 `description` | 你的名字 + 一句话定位 |
| 首屏 `.hero` | 名字、城市、状态、一句话介绍、邮箱 |
| 作品 `.card`（2 个） | 标题、年份、一句话描述、标签 |
| 学员时间线 `STUDENTS` | 脚本里的数组，一个学生一条，详见《编辑指南》第四节 |
| 关于 `.about` | 3–5 行介绍 + 下方的事实清单 |
| 联系 `.contact` | 邮箱（全站 3 处 `mailto:`） |
| 页脚 | 名字 |

**配色**：只改 `styles.css` 顶部 `:root` 里的几个变量即可，`--pink` 是首屏底色，`--yellow` 是数字条和按钮。

### 换成真图

1. 建一个 `assets/` 文件夹，图片放进去。宽度 1600px 以内、转成 WebP、单张控制在 300KB 以下。
2. 把每个 `.cover` 里的两行 `<span class="cover-num">` / `<span class="cover-hint">` 删掉，换成：

```html
<img src="assets/project-1.webp" alt="项目一的封面">
```

3. `styles.css` 里已经留好了注释，取消这一行的注释即可：

```css
/* .cover img { position:absolute; inset:0; width:100%; height:100%; object-fit:cover; } */
```

4. 同时可以删掉 `.c1`–`.c4` 那四段渐变背景。

## 3. 部署到 EdgeOne Pages（推荐）

腾讯云 EdgeOne 的前端托管，基本就是「国内能用的 GitHub Pages + Vercel」：免费、连 Git 自动部署、有免费 HTTPS 和二级域名。

### 方式 A：直接拖拽上传（不用 Git，最快，1 分钟）

1. 打开 <https://pages.edgeone.ai/zh/drop>
2. 把整个 `portfolio` 文件夹拖进去（或先压成 zip 再拖）
3. 等十几秒，拿到 `https://xxx.edgeone.app` 的链接

缺点：以后改了要重新拖。适合先上线看看效果。

### 方式 B：连 Git 仓库（推荐长期用，push 就自动部署）

1. 在 GitHub / GitLab 新建一个仓库，把 `portfolio` 里的文件推到根目录。
2. 打开 <https://console.tencentcloud.com/edgeone/makers>，用微信或手机号注册/登录腾讯云（**需要实名认证**，国内平台都一样）。
3. 新建项目 → 导入 Git 仓库 → 授权并选择刚建的仓库。
4. 配置：
   - 框架预设：选「其他 / 静态站点」
   - 构建命令：**留空**
   - 输出目录：`/`（或留空）
5. 点部署，等 1–2 分钟，拿到免费域名。
6. 以后本地改完 `git push`，它会自动重新部署。

### 免费额度与备案的实话

- 免费版是**永久免费**，不是试用。额度约每月 50GB 流量，个人作品集基本用不完；官方说明即使超了也不会立刻断服。
- **不备案**：域名能访问，国内首次打开大约 200ms–1.4s，之后靠缓存会快一些。
- **想国内 50–90ms**：需要绑自己的域名并完成 ICP 备案。备案本身不收费，但要 1–3 周，且需要国内接入资源；域名约 ¥60–100/年。

**建议**：先用免费二级域名上线，把作品和文案打磨好；确定要长期挂着，再买域名备案。

## 4. 备选方案

| 平台 | 什么时候用 |
|---|---|
| **Cloudflare Pages** | 访客主要在海外；免费额度更大，但国内联通晚高峰会明显卡 |
| **GitHub Pages** | 只给海外/技术圈看；国内访问很慢，不建议作为主站 |
| **Vercel** | 不建议：国内经常直接打不开 |

## 5. 上线前检查清单

- [ ] 用手机 4G（不是 Wi-Fi）打开一次，看多久能出来
- [ ] 所有图片都压缩过，单张 < 300KB
- [ ] 每个项目链接都能点开，没有 `href="#"`
- [ ] 邮箱地址正确，点一下能唤起邮件客户端
- [ ] 标题和描述改过（分享到微信/小红书时的卡片会用到）
- [ ] 删掉了模板里的占位文字和「你的名字」
- [ ] 找一个人在 10 秒内说得出「你是做什么的」

---

## 6. 内容上的建议

- **只放 3–6 个项目**，宁缺毋滥。每个项目写清楚：背景 → 你的角色 → 做了什么 → 结果。
- 有数据就写数据（转化率、耗时、覆盖人数），没有就写清楚规模和难点。
- 网站是「完整叙事」，另外导一份 **PDF 作品集**，很多 HR 会直接要。
- 别追求动效。加载快、字看得清、图够大，比什么都强。
